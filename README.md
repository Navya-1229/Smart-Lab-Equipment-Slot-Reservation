# Smart Lab Equipment & Slot Reservation Portal

## Software Engineering Lab

This project focuses on designing a Smart Lab Equipment & Slot Reservation Portal for campus and academic operations.

## Component Modelling & Architectural Pattern Selection

### Objective
To evaluate different architectural styles and design the system using a UML Component Diagram showing components, interfaces, dependencies, and interactions.

### Target Actors
- Student
- Lab Technician

### Architectural Styles Evaluated
- Layered Architecture
- Microservices Architecture
- Client-Server Architecture

### Selected Architecture
**Layered Architecture**

Layered Architecture was selected because it provides clear separation of responsibilities, is easy to understand and maintain, and is suitable for managing user authentication, equipment, slot reservations, notifications, and database operations.

### System Components
1. **User Management Component** – Handles user login, registration, and authentication.
2. **Slot Reservation Component** – Handles viewing, booking, and cancellation of lab slots.
3. **Equipment Management Component** – Handles equipment details and availability.
4. **Notification Component** – Handles reservation and cancellation notifications.
5. **Database Component** – Stores user, equipment, slot, and reservation information.

### Interfaces
- User Authentication API
- Equipment Availability API
- Reservation Data (DB Queries)
- Reservation Notification API
- Equipment Data (DB Queries)
